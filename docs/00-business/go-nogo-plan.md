# 事業版へのGO / NO-GO 判断計画書

作成日: 2026-07-26 / 判断時期: **家族版リリースから2ヶ月後**

> 本書は「家族版を作った後、**事業版に進むかどうか**」を決めるための計画。
> 事業を始めた後の撤退基準は `exit-plan.md`（別物なので混同しないこと）。

---

## 1. 判断の位置づけ

```
家族版リリース → 【評価期間 2ヶ月】 → ★GO/NO-GO判断★ → 事業版の実装（3〜4ヶ月）
```

- **評価期間の費用は0円**（Supabase Free / Vercel Hobby）
- NO-GO でも家族版は動き続ける。**「見送り」であって「撤退」ではない**
- 判断を先送りにしない。**期日を決めて必ず結論を出す**

---

## 2. 判断基準

### 2.1 必須条件（すべて満たさなければ NO-GO）

| # | 条件 | 測り方 | しきい値 |
|---|---|---|---|
| A | **娘が使い続けている** | 週あたりの学習日数 | **週2日以上が2ヶ月継続** |
| B | **自分が使い続けている** | 同上 | 週1日以上 |
| C | **原価が想定内** | `usage_logs` の実測 | 記事1本 **5円以下**、1人あたり月50円以下 |
| D | **技術的な破綻がない** | 障害・データ欠損の発生 | 復旧不能な事故が0件 |

**A が最も重要。** 作者の家族が使わないものを他人が使うことはない。

### 2.2 GO の条件（必須条件に加えて、1つ以上）

| # | 条件 | 意味 |
|---|---|---|
| E | **目利きの言語化ができた** | 「教材にする価値がある記事」の判断基準が、他人（LLM）に指示できる形になっている |
| F | **記事フィードの試作が動いた** | 手動でよいので、キーワードから教材が生成できることを確認済み |
| G | **外部の需要の兆候がある** | 家族以外から「使いたい」と言われた、など |

**E は事業の中核。** ここが言語化できないなら、作っても商品にならない。

### 2.3 NO-GO の条件（1つでも該当）

| # | 条件 |
|---|---|
| X | 娘が2週間以上使っていない |
| Y | 実測原価が想定の3倍を超えた（記事1本15円超） |
| Z | 目利きの言語化に2ヶ月かけても目処が立たない |
| W | 本業・生活の状況が変わり、月10時間を確保できない |

---

## 3. 判断のために測ること

評価期間中に**必ず記録する**（`../20-plans/family-evaluation-plan.md` に手順）。

| 指標 | 取得元 | 用途 |
|---|---|---|
| 学習日数・頻度 | `practices` / `assessments` テーブル | 条件A・B |
| 実消費トークン | `usage_logs` | 条件C（原価1.74円の裏取り） |
| 発音スコアの推移 | `assessments.scores` | 商品価値の裏付け（上達しているか） |
| 娘の感想 | 対話記録 | 定性評価。**数字より重い** |
| 障害・不具合 | 手記録 | 条件D |

---

## 4. 判断の進め方

1. 評価期間終了時に、上記の指標を1ページにまとめる
2. §2 の表を上から順に埋める（**主観で埋めない。数字と事実で埋める**）
3. 必須条件A〜Dを1つでも満たさない → **NO-GO**
4. 必須条件を満たし、E〜Gのいずれか → **GO**
5. どちらとも言えない場合 → **評価期間を1ヶ月延長する**（判断を曖昧にしたまま実装に入らない）

---

## 5. NO-GO の場合にどうするか

**何も失わない。**

| 項目 | 状態 |
|---|---|
| 家族版 | **そのまま使い続ける**（月130円） |
| 費やした時間 | 家族が使うアプリとして残る＝無駄にならない |
| 金銭的損失 | ほぼ0円（Free枠内で運用） |
| 再挑戦 | いつでも可能。判断材料が増えているぶん有利 |

NO-GO は失敗ではなく、**「今は事業にしない」という選択**にすぎない。

---

## 6. GO の場合の直後の作業

1. Supabase を Pro に上げる（月25ドル）か、Free のまま様子を見るか決める
2. `../10-specs/saas-diff-spec.md` に沿って記事フィードを実装
3. Stripe 契約・法務対応（利用規約・特商法・プライバシーポリシー）
4. **年払いは最初は出さない**（`exit-plan.md` §3。返金債務を抱えないため）
